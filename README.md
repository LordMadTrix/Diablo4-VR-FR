# Diablo IV VR - Édition Française (Diorama 3D Stéréoscopique)
### Par LordMadTrix

Ce projet transforme **Diablo IV** en une expérience stéréoscopique immersive en vue **Diorama 3D** (maquette vivante) sous OpenXR / SteamVR pour Meta Quest 3, Valve Index et casques PCVR.

## Fonctionnalités Clés
- **Rendu Diorama 3D Stéréoscopique** : Immersion en relief avec profondeur volumétrique.
- **NVIDIA DLSS 3.7+ & Frame Generation** : Fluidité maximale 120 FPS et anti-aliasing sans scintillement.
- **Optimisation Quest 3** : Compatibilité sans-fil Wi-Fi 6 ALVR & WiVRn.
- **Installateur Graphique Dédié** : `Diablo4VR-Setup.exe` avec thème Sanctuaire gothique.
